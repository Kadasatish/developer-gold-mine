# Developer Gold Mine

A personal, curated library of useful open-source projects, developer tools, templates, APIs, and learning resources.

> This repository stores **catalogue entries and links** to upstream projects. It does not copy or redistribute their source code.

## How to use this library

1. Open a category and choose a project.
2. Visit its upstream GitHub repository.
3. Read its README, documentation, prerequisites and recent activity.
4. Check its LICENSE before copying, modifying, hosting or using it for a client.
5. Test it in a separate project before integrating it into a production app.

## Adding a new resource

Add a Markdown entry under the most relevant file in `categories/`. Use this format:

```md
### Project name
- Repository: https://github.com/owner/repository
- Purpose: What it does.
- Stack: Main technologies, if confirmed.
- Notes: Setup, maintenance or compatibility notes.
- License: Add only after checking the upstream LICENSE file.
```

For a new category, create another `.md` file inside `categories/` and add its link to the table above.

## Important checks

- A public GitHub repository is not automatically free for commercial use.
- Verify the upstream LICENSE and any third-party dependency licenses.
- Check maintenance status, security advisories, release history and deployment requirements.
- Never commit API keys, passwords, service-account files or private customer data here.
