# React & UI Components

Reusable UI libraries and curated React resources.

### shadcn/ui
- Repository: https://github.com/shadcn-ui/ui
- Purpose: Reusable UI components designed to be copied into applications.
- Stack: React, Tailwind CSS and Radix UI ecosystem.
- Notes: Review component dependencies and adapt styling to the client brand.
- License: Verify in the upstream repository.

### Awesome React
- Repository: https://github.com/enaqx/awesome-react
- Purpose: Curated React libraries, tools and learning resources.
- Stack: React ecosystem.
- Notes: Use it to discover focused libraries rather than adding every dependency.
- License: Verify in the upstream repository.

### Lucide
- Repository: https://github.com/lucide-icons/lucide
- Purpose: Consistent open-source icon set and framework integrations.
- Stack: Multiple frameworks, including React.
- Notes: Useful for consistent navigation and action icons.
- License: Verify in the upstream repository.
