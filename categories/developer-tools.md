# Developer Tools & Curated Collections

Useful directories and tools for discovering, operating and maintaining software.

### Awesome
- Repository: https://github.com/sindresorhus/awesome
- Purpose: Index of curated awesome lists across many topics.
- Stack: Resource directory.
- Notes: Use it to discover specialist lists.
- License: Verify in the upstream repository.

### Free for Dev
- Repository: https://github.com/ripienaar/free-for-dev
- Purpose: Directory of free tiers for developers and open-source projects.
- Stack: Resource directory.
- Notes: Free tiers and limits change; confirm current pricing and terms with each provider.
- License: Verify in the upstream repository.

### Awesome Selfhosted

- License: Verify in the upstream repository.
