# SaaS, CRM & Commerce

Larger business applications and platforms. These are not necessarily lightweight PWA starters; check hosting and server requirements before choosing one for a client.

### Twenty CRM
- Repository: https://github.com/twentyhq/twenty
- Purpose: Open-source CRM platform.
- Stack: TypeScript ecosystem.
- Notes: Useful to study CRM data models, pipelines and user experience. Review deployment requirements.
- License: Verify in the upstream repository.

### Medusa
- Repository: https://github.com/medusajs/medusa
- Purpose: Composable commerce platform and commerce backend.
- Stack: TypeScript, Node.js ecosystem.
- Notes: Suitable for more advanced commerce builds; assess infrastructure needs.
- License: Verify in the upstream repository.

### ERPNext
- Repository: https://github.com/frappe/erpnext
- Purpose: ERP covering business operations such as accounting, inventory and HR.
- Stack: Frappe framework, Python.
- Notes: Full business platform; not a simple React/Firebase starter.
- License: Verify in the upstream repository.

### Saleor
- Repository: https://github.com/saleor/saleor
- Purpose: Headless commerce platform.
- Stack: Python, GraphQL ecosystem.
- Notes: Review deployment complexity and API requirements.
- License: Verify in the upstream repository.
