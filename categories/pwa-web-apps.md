# PWA & Web App Starters

Resources for building installable, offline-capable web applications.

### Vite PWA
- Repository: https://github.com/vite-pwa/vite-plugin-pwa
- Purpose: Integrates Progressive Web App capabilities into Vite projects.
- Stack: Vite ecosystem.
- Notes: Useful for manifest generation and service-worker integration. Review the current docs for the supported Vite version.
- License: Verify in the upstream repository.

### Workbox
- Repository: https://github.com/GoogleChrome/workbox
- Purpose: Libraries and build tools for service-worker caching strategies.
- Stack: JavaScript.
- Notes: Useful for offline caching; choose caching rules carefully for authenticated or frequently changing data.
- License: Verify in the upstream repository.

### Awesome PWA
- Repository: https://github.com/hemanth/awesome-pwa
- Purpose: Curated PWA tools, articles and examples.
- Stack: Resource collection.
- Notes: A discovery list, not an app template.
- License: Verify in the upstream repository.
