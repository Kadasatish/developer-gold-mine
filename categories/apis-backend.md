# APIs & Backend

Directories of APIs and backend frameworks for application development.

### Public APIs
- Repository: https://github.com/public-apis/public-apis
- Purpose: Community-maintained directory of public APIs.
- Stack: API catalogue.
- Notes: Check each API's authentication, rate limits, CORS support, data freshness and terms independently.
- License: Verify in the upstream repository.

### Express
- Repository: https://github.com/expressjs/express
- Purpose: Minimal Node.js web framework for HTTP APIs and servers.
- Stack: Node.js, JavaScript.
- Notes: Add authentication, validation, logging and security middleware appropriate to the app.
- License: Verify in the upstream repository.

### Hono
- Repository: https://github.com/honojs/hono
- Purpose: Lightweight web framework for APIs across several JavaScript runtimes.
- Stack: TypeScript, JavaScript.
- Notes: Check adapter and runtime compatibility before deployment.
- License: Verify in the upstream repository.

### Fastify
- Repository: https://github.com/fastify/fastify
- Purpose: Web framework for building Node.js APIs.
- Stack: Node.js, JavaScript/TypeScript.
- Notes: Review its plugin ecosystem and schema validation approach.
- License: Verify in the upstream repository.
